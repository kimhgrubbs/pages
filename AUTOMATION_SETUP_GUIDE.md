## PART 6: VIDEO & IMAGE SPECIFICATIONS

### **Instagram Reel Requirements**
- **Duration**: 15-30 seconds
- **Aspect Ratio**: 9:16 (vertical, full screen on phones)
- **Video Codec**: H.264
- **Audio Codec**: AAC
- **File Size**: Max 500MB
- **Resolution**: 1080 x 1920 pixels (minimum)
- **Frame Rate**: 30fps
- **Audio**: Yes (trending audio recommended)

**Editing Tools for Reels**:
- Adobe Premiere Pro (professional)
- CapCut (free, easy for short videos)
- DaVinci Resolve (free, powerful)
- InShot (mobile app, simple)

### **Instagram Carousel Requirements**
- **Number of Images**: 5-7 (per post)
- **Aspect Ratio**: 1:1 (square) or 4:5 (mobile-optimized)
- **Image Size**: Max 8MB each
- **Resolution**: 1080 x 1080 pixels (minimum)
- **Format**: JPG or PNG
- **Color Space**: sRGB (for web viewing)

**Design Tools for Carousels**:
- Canva (templates, easy)
- Adobe Photoshop (professional)
- Figma (collaborative design)
- Unsplash/Pexels (free stock images)

### **Facebook Cross-Post Specs**
- **From Instagram Reels**: Automatically optimized
- **From Instagram Carousel**: Automatically optimized
- **Facebook Native Posts**: Same specs as Reel (Reels auto-convert to Facebook format)

## PART 13: TROUBLESHOOTING

### **Issue: Post Not Scheduled**
- **Solution**: In Buffer, check if Instagram account is still connected (sometimes sessions expire). Re-authenticate if needed.

### **Issue: Video Not Uploading**
- **Solution**: Check file format (must be MP4, H.264 codec). Check file size (max 500MB). Try re-encoding in CapCut or Adobe.

### **Issue: Captions Look Wrong in Preview**
- **Solution**: Instagram mobile/web preview may show different line breaks. Test on actual Instagram app before publishing.

### **Issue: Hashtags Not Working**
- **Solution**: Check for typos. Check if hashtag is shadowbanned (blocked). Avoid special characters. Use 8-10 hashtags max.

### **Issue: Link in Bio Not Tracking**
- **Solution**: Check UTM parameters in Google Analytics. Verify link was clicked (check Google Analytics "Traffic Source = instagram"). May take 24 hours to appear.

### **Issue: Facebook Post Different Than Instagram**
- **Solution**: Facebook may reformat carousel images or video thumbnails. This is normal. Test by posting to Facebook and viewing on different devices.
