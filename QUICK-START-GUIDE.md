## Common Questions Answered

**Q: Can I change the colors?**  
A: The primary orange (#FF6B35) is core to Pecron positioning. Accent teal/coral can be adjusted if needed, but maintain the same saturation level. Neutrals should stay warm-toned (avoid cold grays).

**Q: What if I need more email templates?**  
A: Use templates 01-06 as the structure model. Maintain the 600px width, inline CSS, same font stacks, and brand color hierarchy.

**Q: Where do I get social media graphics?**  
A: Use Figma or Adobe Suite with the specifications provided. Create component libraries so you can swap out product photos/colors quickly.

**Q: How do I test the email templates?**  
A: Copy the HTML into Mailchimp/ConvertKit/HubSpot preview. Test across: Gmail (desktop/mobile), Outlook (desktop), Apple Mail, iPhone Mail, Gmail mobile.

**Q: What if social platform dimensions change?**  
A: Social specs change quarterly. Re-check platform specifications before major campaigns. This system will be updated accordingly.

**Q: Can I add new products later?**  
A: Yes. Assign each new product its own accent color (similar to teal for Berkey, coral for LETPOT). Update brand guidelines and social templates to reflect new product line.
