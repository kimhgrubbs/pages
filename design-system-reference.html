Button Requirements

Minimum touch target: 44×44px. All buttons must maintain 4.5:1 contrast ratio against background. Focus states must be visible (4px outline in brand color). Use consistent font weight (600) for button text.

Accessibility Minimums

Standard Requirement Implementation
Text Contrast WCAG AA (4.5:1) All text must meet minimum ratio. Test with WebAIM contrast checker.
Focus States Visible on all interactive elements 4px outline in brand color. Keyboard navigation fully supported.
Line Height 1.5 minimum for body text Improves readability, especially for dyslexic readers.
Letter Spacing 0.12em for all caps Improve readability of uppercase labels and headings.
Color Information Never rely on color alone Use icons, text, patterns to reinforce information.
Motion Respect prefers-reduced-motion Disable animations for users who prefer reduced motion.

File Naming & Organization

CSS Variables

--color-primary-orange | --color-accent-teal | --font-display | --font-body

Use CSS variables for all color and typography references. Never hardcode hex values in component styles.

Image Optimization

Format: WebP with JPEG fallback | Minimum width: 2400px (web) | Maximum file size: 200KB (web images) | Compression: Lossless for PNG, 75–80 quality for JPEG

Email HTML

Inline all CSS in <style type="text/css"> tags. No external stylesheets. Use 600px max-width for email containers. Test across major email clients (Gmail, Outlook, Apple Mail). Use system fonts with @font-face fallbacks only for critical display fonts.
