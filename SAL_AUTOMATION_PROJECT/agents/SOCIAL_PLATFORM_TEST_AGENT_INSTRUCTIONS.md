## Troubleshooting Guide

**If post won't publish:**
1. Check account has posting permissions
2. Verify account is not restricted/banned
3. Check content doesn't trigger spam filter
4. Test with simpler content if available
5. Check internet connection
6. Try again after 5 minutes

**If link is broken:**
1. Verify URL in SAL.com is correct
2. Test link directly in browser
3. Check for encoding issues
4. Try with UTM parameters removed
5. Verify domain is accessible

**If formatting looks wrong:**
1. Check platform-specific character limits
2. Verify line breaks are preserved
3. Check emoji rendering (may vary by platform)
4. Try re-posting with adjusted formatting
5. Document platform quirks for future reference
