## TROUBLESHOOTING QUICK START

**Problem**: Can't connect Instagram to Buffer  
**Solution**: Make sure account is Business account, not personal. Use Instagram business account settings to authorize Buffer.

**Problem**: Videos won't upload  
**Solution**: Check file format (MP4 recommended), size under 100MB, length 15-30 sec. Try shorter clip if issues persist.

**Problem**: Caption shows formatting errors (weird line breaks)  
**Solution**: Copy/paste from plain text file, not formatted document. Use ALL_36_POSTS_BUFFER_REFERENCE.md for cleanest copy.

**Problem**: Can't find post in calendar after scheduling  
**Solution**: Refresh page. Check filter settings - make sure Instagram is selected. Look at correct month.

**Problem**: Test post didn't appear on Facebook  
**Solution**: Check that cross-posting is enabled in settings. Allow 5 minutes for auto-cross. Manual share may be needed if auto fails.

**Problem**: Running out of time  
**Solution**: You don't need to finish all 36 before deadline - buffer accepts scheduled posts. Just complete setup + Week 1 by deadline, upload rest later.
