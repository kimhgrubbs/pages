Each agent will document any issues in their deployment report. Common blockers:

- Google Analytics Property ID
- Shopify Access Token
- Platform access issues

**Can't connect to external services?**
- Document the error
- Contact support
- Alternative approach identified

**Email won't send?**
- Check account permissions
- Verify email list configured
- Test with simpler template

**See troubleshooting_guide.md for complete list**
