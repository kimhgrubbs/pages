## REAL-TIME TROUBLESHOOTING GUIDE

### Problem: Post Didn't Go Live at Scheduled Time

**Diagnosis:**
1. Check Buffer account (was it scheduled correctly?)
2. Check TikTok account (did post appear in drafts?)
3. Check internet connection (Buffer might not have sent)

**Solution:**
- Option 1: Wait 15 minutes (Buffer may be delayed)
- Option 2: Manually post from TikTok app immediately
- Option 3: Post to Facebook/Instagram as backup
- Note: Don't post twice (avoid duplicate content)

**Prevention:**
- Test Buffer 24 hours before by scheduling a test post
- Have manual posting app ready as backup
- Set phone alarm for 5pm ET to manually verify

---

### Problem: Video Quality Poor on Mobile

**Diagnosis:**
- Video appears pixelated, blurry, or compressed

**Solution:**
1. Check video resolution (should be 1080x1920)
2. Reupload from original file (not compressed)
3. Check internet speed (upload with high-speed connection)
4. Use CapCut export settings: 1080x1920, high quality

**Prevention:**
- Always preview on mobile before uploading
- Test first post early to catch quality issues
- Use high-quality source footage

---

### Problem: Link in Bio Not Working

**Diagnosis:**
- Clicks don't go to website
- Error message appears

**Solution:**
1. Verify link in TikTok bio is correct (no typos)
2. Check: SuppliesAreLimited.com/?utm_source=tiktok&utm_medium=social&utm_campaign=sept_launch
3. Test link on multiple devices
4. Verify domain pointing correctly (DNS settings)

**Prevention:**
- Test link every Monday morning
- Use URL shortener (bit.ly) as backup
- Monitor link clicks in Google Analytics

---

### Problem: Comments Asking Questions About Products

**Diagnosis:**
- Multiple comments with product questions
- Same questions appearing repeatedly

**Solution:**
- Respond to each comment individually (builds trust)
- Common questions: Pin response to top comment
- Add more detail to caption for future posts
- Create FAQ in bio (link to FAQ page)

**Prevention:**
- Add key specs/FAQs to caption
- Include "Link in bio for full details"
- Reference competitor comparisons in captions

---

### Problem: Low Engagement on Certain Posts

**Diagnosis:**
- Less than 2,000 views or 2% engagement

**Solution:**
1. Analyze what went wrong:
   - Was audio trending? (Maybe not optimal choice)
   - Was hook compelling? (Maybe too subtle)
   - Did video start boring? (2-sec hook critical)
   - Wrong posting time? (Check Buffer time)
2. Don't panic (some posts underperform, algorithm varies)
3. Note what to avoid for future posts
4. Double down on what worked

**Prevention:**
- Always use strong 2-sec hook
- Test trending audio before main content
- Ensure first 3 frames are visually interesting
- Post at consistent time (algorithm learns your schedule)
