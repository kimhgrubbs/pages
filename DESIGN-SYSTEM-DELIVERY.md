## TYPOGRAPHY SYSTEM

### Font Families
1. **Playfair Display** (serif) — Headlines, premium brand statements
   - Google Fonts (reliable web font)
   - Fallback: Georgia, serif

2. **Inter** (sans-serif) — Body text, UI elements, captions
   - Google Fonts (highly recommended)
   - Fallback: -apple-system, BlinkMacSystemFont, Segoe UI, sans-serif

3. **IBM Plex Mono** (monospace) — Data, timestamps, code
   - Google Fonts
   - Fallback: Courier New, monospace

### Type Scale
- **H1:** 56px, Playfair Display 700, line-height 1.2
- **H2:** 40px, Playfair Display 600, line-height 1.2
- **H3:** 28px, Playfair Display 600, line-height 1.3
- **H4:** 16px, Inter 600, line-height 1.4
- **Body:** 16px, Inter 400, line-height 1.7 (max width 65ch)
- **Small:** 14px, Inter 400, line-height 1.6
- **Tiny:** 12px, IBM Plex Mono 500, line-height 1.5

## SPACING SYSTEM (8px Grid Foundation)

- **XS:** 8px (micro spacing)
- **SM:** 16px (component padding)
- **MD:** 24px (internal spacing)
- **LG:** 32px (card padding)
- **XL:** 48px (major section spacing)
- **2XL:** 64px (large breaks)

## RESPONSIVE BREAKPOINTS

- **Mobile:** 320px–768px (24px padding)
- **Tablet:** 768px–1024px (40px padding)
- **Desktop:** 1024px–1440px (64px padding)
- **Large Desktop:** 1440px+ (64px padding)

## BRAND VOICE & TONE

**Key Characteristics:**
- **Credible:** Research-backed, specific, transparent
- **Confident:** No apologies or over-explanation
- **Measured:** Acknowledges reality without panic
- **Sophisticated:** Premium language for high-income audience
- **Clear:** Active voice, specific naming conventions

**Tagline:** "Don't Panic. Pay Attention. Prepare."

**Mission:** Research-backed resilience for high-income professionals (100K+)

**Positioning:** Premium preparation, NOT survivalism. Sophisticated, mature, aspirational.

## ACCESSIBILITY COMPLIANCE

All templates and designs meet minimum accessibility standards:
- **Text Contrast:** WCAG AA (4.5:1 minimum)
- **Focus States:** Visible on all interactive elements
- **Line Height:** 1.5 minimum for body text
- **Letter Spacing:** 0.12em for uppercase labels
- **Alternative Text:** All images have descriptive alt text
- **Motion:** Respects prefers-reduced-motion preferences
- **Captions:** All video includes captions/subtitles
