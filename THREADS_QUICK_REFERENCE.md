## WHAT TO DO WHEN...

### "Post not publishing at scheduled time"
→ Check Meta Business Suite
→ Restart app
→ Manually publish as backup
→ Contact Meta support

### "No comments/engagement"
→ Normal weeks 1-2 (audience building)
→ Week 3+ should show growth
→ If still low: Reply faster, change posting time, adjust content angle

### "Getting spam/trolls"
→ Delete obvious spam
→ Ignore trolls seeking reaction
→ Don't respond to harassment
→ Block if necessary

### "Can't keep up with replies"
→ Prioritize high-intent users first (people asking about buying)
→ Use templates (saves 50% time)
→ Set 30-minute engagement window, then step away
→ Get backup person for overflow

### "Links getting marked as spam"
→ Use bit.ly for long URLs
→ Verify UTM parameters are correct
→ Check domain reputation
→ Contact Threads support if falsely flagged

## ENGAGEMENT PRIORITIES (In Order)

1. **High-Intent Users**: "How do I order?" "Where can I buy?" "What's the price?"
   → Reply in <15 minutes with link

2. **Genuine Questions**: Technical questions, comparisons, use cases
   → Reply in <30 minutes with detailed answer

3. **Stories/Testimonials**: People sharing experiences
   → Reply with validation and "can we feature this?"

4. **Skeptics**: Real doubt, good-faith pushback
   → Reply with data and honest assessment

5. **Praise**: "Great post!" "Love this" etc.
   → Like and move on (unless asking questions)

6. **Spam/Trolls**: Unrelated, seeking reaction, harassment
   → Delete or ignore (don't feed trolls)
