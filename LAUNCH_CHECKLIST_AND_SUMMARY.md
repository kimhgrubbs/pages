## CRITICAL SUCCESS FACTORS

### ✅ Must Do
1. **Post on schedule** (9am ET, every Mon/Wed/Fri)
   - Algorithm favors consistency
   - Audience expects it
   - Builds habit

2. **Respond to comments quickly** (within 2 hours)
   - Increases engagement rate
   - Builds community
   - Improves algorithm visibility

3. **Track metrics** (weekly spreadsheet)
   - Know what's working
   - Optimize content week-by-week
   - Prove ROI to stakeholders

4. **Verify links** (test before posting)
   - Wrong link = lost traffic
   - Breaks conversion funnel
   - Wastes potential sales

### ❌ Must NOT Do
1. Don't schedule and forget
   - Engagement requires daily attention
   - Comments need responses
   - Metrics need tracking

2. Don't use same hashtags every post
   - Algorithm sees it as spam
   - Limits reach
   - Audiences tune out

3. Don't post at random times
   - Consistency = algorithm boost
   - Audience learns schedule
   - Performance suffers with randomness

4. Don't ignore underperforming content
   - Learn from failures
   - Test new themes
   - Optimize continuously

## RED FLAGS & EARLY WARNING SIGNS

### Watch For These Week 1

⚠️ **Post Didn't Publish**
- Likely cause: Scheduling tool connection lost
- Fix: Re-authenticate account in Buffer/Meta Business Suite
- Prevention: Check scheduler 1 hour before posting

⚠️ **Video Quality Poor**
- Likely cause: Wrong video format/codec
- Fix: Re-encode using CapCut or Adobe Premiere
- Prevention: Test video specs before uploading

⚠️ **Link Broken**
- Likely cause: Typo in UTM parameters
- Fix: Update link immediately before posting
- Prevention: Test all links before uploading

⚠️ **Engagement Very Low** (below 10 likes by 6 hours)
- Likely cause: Hook isn't strong, algorithm needs tweaking
- Fix: Double-check posting time, improve captions, test new hooks
- Prevention: Monitor first 2 hours post closely

⚠️ **Comments Mostly Spam**
- Likely cause: Hashtags attracting wrong audience
- Fix: Switch hashtags, block spammy accounts
- Prevention: Monitor hashtag quality weekly

## TROUBLESHOOTING QUICK REFERENCE

| Problem | Cause | Solution |
|---------|-------|----------|
| Post won't schedule | Account not connected | Re-authenticate Buffer/Meta Business Suite |
| Video won't upload | Wrong format/codec | Re-encode in CapCut (MP4, H.264, 1080x1920) |
| Link broken | Typo in URL | Test link before posting, fix UTM parameters |
| Engagement very low | Poor hook/timing/content | Check first 2 seconds of video, test new hashtags |
| Hashtags not working | Banned hashtags or typos | Search hashtag on Instagram, verify it exists |
| Facebook cross-post looks weird | Format conversion | This is normal, image quality still good |
| Comments section disabled | Restricted account | Check Instagram account settings (shouldn't be restricted) |
| Can't access scheduling tool | Login issue | Reset password, clear cookies, try different browser |
